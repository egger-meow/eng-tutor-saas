# 紙屬英文 (Paper English) 資料保存與銷毀政策 (Data Retention & Disposal Policy)

**生效日期：** 2026-08-16  
**法規基準：** 中華民國《個人資料保護法》、《商業會計法》、《稅捐稽徵法》  

---

## 1. 資料保存分類標準 (Retention Schedule by Category)

| 資料類別 | 保存目的 | 保存期限 | 銷毀／匿名化方式 |
| :--- | :--- | :--- | :--- |
| **1. 學生學習檔案與記憶**<br>（暱稱、年級、學習目標、單字進度、文法狀態、錯題紀錄、家長回饋） | 提供每週適性化教材生成與學習歷程延續 | **家長帳號與孩子檔案存續期間**。<br>若家長主動刪除孩子檔案，立即於線上資料庫永久刪除。 | 資料庫 `ON DELETE CASCADE` 永久清除。無法復原。 |
| **2. 歷史每週生成教材 (PDF & JSON)** | 供家長於訂閱期間隨時回顧與補印 | **訂閱存續期間**。<br>若訂閱終止或帳號刪除，PDF 檔案保留 30 天緩衝期後自儲存庫完全清除。 | 自 Supabase Storage (`weekly-materials`) 呼叫 API 永久刪除物件。 |
| **3. 家長帳號認證資料**<br>（Email、名稱、登入紀錄） | 會員身分識別與存取控制 | **帳號存續期間**。<br>家長申請註銷帳號後 7 日內完全刪除。 | 自 Supabase Auth 與 `public.profiles` 永久刪除。 |
| **4. 法律條款同意紀錄**<br>（`terms_version`, `privacy_version`, `accepted_at`） | 證明履行法令告知與同意義務 | **帳號存續期間至註銷後 5 年**（民法契約請求權時效範圍）。 | 逾期後資料庫批次排程抹除。 |
| **5. 訂閱與財務交易對帳紀錄**<br>（訂閱 ID、金額、交易時間、發票號碼、退費紀錄） | 遵循稅捐稽徵與商業會計法規 | **自交易成立起 5 年至 7 年**（《商業會計法》第38條、《稅捐稽徵法》第11條）。 | 獨立留存於財務對帳庫，與已刪除之學生個人學習資料完全脫鉤。 |
| **6. 系統與伺服器日誌 (Logs)** | 資安監控、除錯、防範惡意攻擊 | **最長 90 天**。 | 自動滾動覆蓋／銷毀。日誌中一律去識別化，不記錄學生真實個資。 |
| **7. 候補登記名單 (Waitlist)** | 容量開放時發送註冊通知 | **名額開放通知發送後 30 天**，或當事人隨時要求撤回。 | 手動或排程清空該筆登記。 |

## 2. 當事人行使刪除權 (Right to Erasure) 實施作業流程

當家長於介面點擊「刪除孩子學習檔案」或向客服提出「註銷家長帳號」時，系統執行以下作業：

1. **第一步（線上資料庫連鎖刪除）：**
   - 執行 `DELETE FROM public.children WHERE id = $1 AND parent_id = auth.uid()`
   - 由於資料庫設定 `ON DELETE CASCADE`，下列關聯資料表之所有紀錄將於同一交易內立即永久清除：
     - `child_profiles`
     - `child_vocab_progress`
     - `child_grammar_progress`
     - `child_learning_state`
     - `feedback`
     - `generation_jobs`
     - `materials`
     - `subscriptions`
2. **第二步（私有儲存空間清除）：**
   - 儲存於 `weekly-materials` bucket 之所有該孩子專屬 PDF 檔案（路徑格式為 `{child_id}/{job_id}/...`）將同步由後端排程或觸發器執行物件清除。
3. **第三步（第三方處理者處置）：**
   - 本系統發送給 AI API（OpenAI / LLM）之情境提示詞一律不包含永久持久化之真實身分資料，且依 OpenAI 企業 API 條款，API 資料在處理完畢後不作為模型訓練用途，並於 30 天後自暫存日誌完全清除。
