## Required corrections, in priority order

1. **P1 — Canonical response validation contradicts valid grid/sequence writing space.** packages/generator/src/validate-curriculum-package.ts: relationshipIssues still rejects every short-response with writingLines=0, even with a valid responseLayout. QuestionV25Schema accepts these layouts, but package-level validation rejects them. Execute a complete 2.5 package through the actual Finisher validator, not only QuestionSchema or responseUnitRelationshipIssues. Preserve existing science and guitar examples.
2. **P1 — Response answer integrity and grid shape are incomplete.** responseUnitRelationshipIssues permits conflicting duplicate unitAnswers and skips orphan checking when no units/layout exist. ResponseLayoutRowSchema permits both legacy values and cells and does not bind cell count (including row label) to headers. A synthetic two-header row with label + two cells parses; duplicate u1 answers A/B produce no relationship issues. Define exclusive representations, enforce shape and one-to-one mappings, and retain explicit 2.4 compatibility.
3. **P1 — History cutoff and provenance are not enforced.** history-retrieval.ts returns evidence after cutoffTimestamp; provenanceHash omits result, observedAt, targetType and source/claim identity. Synthetic cutoff September 1 returned October 1 evidence; changing incorrect to correct retained the same hash. Use the immutable claim cutoff; hash the complete canonical retrieved slice and source identity. Missing lifetime index entries cannot establish no prior evidence, especially when targetedOlderEvidence contains a match. Return insufficient/not-retrieved separately from verified absence.
4. **P1 — Delivery identity and shared-contract parity are incomplete.** aggregate_format_memory SQL orders materials by material_week and reads metadata.weekNumber rather than immutable snapshot sequence_number. It returns no pedagogicalFormats although TypeScript requires it, uses different choice/form labels, and lacks source/snapshot linkage, hook/entity/reasoning/scaffold memory. Join completed canonical delivery snapshots, use sequence_number and deterministic ordering, and test actual DB-to-adapter parity. Existing five tests only exercise TypeScript helpers and do not prove online/manual/local parity.
5. **P2 — Parent structured answers are not implemented.** parent-renderer.ts adds a unit answer list, not the completed original table/sequence. Per-unit acceptedAnswers are not rendered. Share structural rendering with Student, fill only Parent, preserve accepted variants, and inspect actual A4 PDFs containing new long-label/partial-scaffold formats. The old synthetic pair does not verify new layouts.
6. **P2 — Selective retrieval is a helper, not the promised context reduction.** The fixed bundle still contains the entire routing index. New retrieval is called only by CLI actions; no reviewed online retrieval contract or author-loop integration was found. History re-filters an already-loaded context and makes no targeted older retrieval. CAP expansion silently drops unknown/missing/unreadable refs. Wire bounded candidates/expansion across entry points, explicit expansion failures and pinned source identities. Measure total all-stage tokens and recall on the same cases before claiming savings.
7. **P2 — Hybrid evaluation claims exceed evidence.** hybrid-search-eval.ts uses bag-of-words term vectors, not semantic embeddings. Its Recall@K counts any hit per case (HitRate@K), not fraction of relevant refs recovered. contextOverheadTokens and childIsolationEnforced are constants; assertChildIsolation is an unconnected helper, not server authorization. Rename the experiment and metrics honestly; do not infer semantic-vector usefulness or production isolation from these four cases. Keep vector adoption deferred pending a real comparison.
8. **P2 — Workload model loses response demand.** computeQuestionDuration uses only slot count whenever units exist, ignoring response length/type and plateauing at eight minutes. One-word classifications and sentence explanations with equal slots receive identical estimates. Add bounded demand representation/calibration and verify examples do not count as assessed responses.
