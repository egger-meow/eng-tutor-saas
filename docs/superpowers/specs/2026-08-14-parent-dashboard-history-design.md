# Parent Dashboard History and Child Profiles

## Goal

讓家長能清楚找到過往教材，並在孩子資料頁一次看到所有自己擁有的孩子。

## Design

- 本週教材維持每個孩子獨立區塊，初始只載入最近五筆教材。
- 每個有歷史教材的孩子區塊固定提供清楚的「查看過往教材」入口；展開後以既有分頁載入方式取得更多資料。
- 孩子資料頁改為所有孩子的縱向清單，不依賴 URL 的單一 child id。每個孩子顯示目前既有的 profile summary，孩子之間以 divider 分隔。
- 訂閱頁維持每個孩子獨立的訂閱區塊，保留一個孩子一個訂閱的邊界。

## Scope

只修改家長後台前端呈現與資料讀取方式，不新增資料表、不改 RLS、不改訂閱模型。
