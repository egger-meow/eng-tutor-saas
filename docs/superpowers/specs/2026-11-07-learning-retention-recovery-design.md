# 紙屬英文：孩子持續使用的產品更新分析

日期：2026-11-07。狀態：規劃完成，尚未實作或驗證改善效果。

## 決策摘要

使用者明確回報：「有註冊，但孩子沒有持續使用」。這是目前最重要的需求證據；尚未取得正式環境的分群留存數字，不能直接判定所有家庭流失的原因。

建議的核心賣點是：**每次打開，都知道今天只要完成哪一小段；下次直接接著做，家長看得懂孩子卡在哪裡。**

「兩週看見進步」保留為後續待驗證價值，不當成保證。孩子沒有第二次作答，就沒有足夠資料證明個人化有效。優先把已存在的短時段學習與接續能力做完整，再驗證跨份教材的學習證據，最後才測試付費轉換。沒有單一功能能保證爆紅。

## 一、已知事實與仍待驗證的解釋

| 證據 | 判斷 | 邊界 |
|---|---|---|
| 使用者回報已有註冊但未持續使用 | 優先診斷啟動與留存 | 不等於已知首次作答率或流失原因 |
| `LearningStartPanel.tsx` 使用 `plan.steps[0]` | 回訪面板仍導向起點，未依已做內容更新主行動 | 原始碼事實，不是正式環境行為錄影 |
| `material-session-plan.ts` 無題目時直接回傳 completed | 閱讀／講解可能尚未進行便顯示勾選 | 勾選不能代表學會 |
| 同檔以 question ID 查答案 | 結構化 response unit 的完成判定需逐題型驗證 | 不能假設所有題型皆有問題 |
| 已有草稿、接續導航、EvidenceCard、LearningJourneySummary | 不應重做一套學習系統 | 應補一致性與證據缺口 |
| `profile-form.ts` 預設每週 90 分鐘 | 第一次只做 10 分鐘與整份工作量可能不一致 | 尚未證實工作量是流失主因 |
| `ScopedMaterialPage.tsx` 限定連結提供預覽／下載，線上作答需要家長登入 | 郵件到作答可能有登入交接阻力 | 不得把預覽 token 升級成作答權限 |
| 現有 SQL 有開啟、作答日期、障礙回報等訊號 | 可先做漏斗基線，無須先建大型分析平台 | 事件缺漏、離線紙本與代答皆有盲點 |
| 管理端把可選試閱列當連續漏斗分母 | 行銷漏斗可能誤導投資順序 | 與孩子留存是不同問題，修正但不優先重做首頁 |

檢查基準為本次 checkout；沒有正式資料查詢、真人訪談或正式環境操作證據。歷史計畫中的百分比不能當成現在的基線。

## 二、先把「沒持續」拆成五種問題

| 掉落位置 | 要確認的事情 | 對應更新 |
|---|---|---|
| 註冊後未拿到可用教材 | 生成失敗、通知未送達、尚未發布？ | 先修交付與狀態，不推新學習功能 |
| 教材已可用但未開始 | 家長找不到入口、登入中斷、孩子不知道做什麼？ | 清楚入口與一個具體起步任務 |
| 開始但第一次就停 | 太難、太長、題目／輸入問題，還是沒空？ | 修操作問題；依證據校準工作量與難度 |
| 做過一次但不回來 | 再次找起點費力、進度不可信、需要家長重新安排？ | 可靠接續、明確下一小段、真實儲存狀態 |
| 第一份做過但第二份不用 | 下一份請求不清楚、等待過久、看不出調整價值？ | 分開請求／交付／使用，說明實際調整依據 |

「家長登入」不是「孩子學習」。下載不代表列印、列印不代表做題；提交也不代表所有題目已完成。現有容量用的活躍定義不可直接拿來當學習留存。

## 三、核心體驗設計

### 第一次：給一個可完成的小任務

沿用既有閱讀與練習內容，提供一個主要入口，例如「先讀這一段，再試兩題」。約 10 分鐘是安排建議，不是每個孩子都能在該時間完成的承諾。不要用過多導覽、進度圖表或長說明擋住學習。

完成指的是已保存的有效作答／明確閱讀自述，不是答對或熟練。閱讀自述必須標示為自述，不從捲動位置推論理解。

### 再次打開：直接接著做

共用一套下一步判定：已提交時顯示提交後流程；未提交時優先提供有效的保存位置與未完成任務。若定位過期則退回有效章節，不導向不存在題目。允許回看已做內容，不強迫單向完成。

主按鈕要根據狀態顯示「開始這一段」「接著做」「查看已提交內容」。所有可作答單位完成時，不再推薦「未完成題目」，也不自動提交整份教材。保留整份提交的明確確認。

儲存失敗時明確說尚未同步，保留草稿與重試；不要在保存失敗時仍承諾換裝置可接續。暫停離開需處理未完成儲存，避免製造不可靠的完成感。

### 家長：少安排一次，而不是多看一張圖

家長頁只需清楚回答：有沒有開始、目前做到哪裡、下次可做什麼、是否需要協助。以既有 dashboard 元件整合，不另建第二份進度來源。家長回饋維持可選，學生提交、回饋、下一份請求仍為三個獨立行為。

## 四、為何不先做其他「爆點」

| 選項 | 可能收益 | 當前判斷 |
|---|---|---|
| 改首頁與增加曝光 | 增加新註冊 | 無法直接處理已註冊孩子流失，暫居次要 |
| 折扣與付費倒數 | 短期改變購買決策 | 免費試辦仍有效；不得違反既有免費權益 |
| 積分、連續登入、排行榜 | 可能增加開啟動機 | SPEC 非目標，開啟也不等於學習 |
| 真人逐日督學 | 可快速了解問題與協助完成 | 用作研究時必須記錄人工介入，不當成軟體自然留存 |
| 兩週進步報告 | 家長較容易理解價值 | 需先有重複使用與可比較的新題證據 |
| 可靠的下一小段與接續 | 直接降低每次重新開始的成本 | 最符合現在的問題，優先驗證 |

市場參考：English Compass 已公開診斷與適性練習；PaGamO 已提供遊戲化英語學習與回饋服務；博幼有診斷與序列教材。這些資料只能支持「診斷、個人化、報表本身不夠獨特」，不能推論其留存率或本產品一定能勝出。

來源：[English Compass](https://english-compass.com/about)、[PaGamO](https://learning.pagamo.org/seca/)、[博幼教材介紹](https://www.boyo.org.tw/boyoV2/online_tm/english_tm_introduction)。產品方案可能改變；本計畫不以價格比較作決策。

## 五、可驗證的留存指標

以 child 為主要單位，另報 parent／家庭去重數。排除內部測試帳號；保留來源、教材序號、版本、人工協助與線上／紙本分層。第一份由 canonical sequence 判定，不用 calendar week 推算。

| 指標 | 分母與時間 | 分子／解釋 |
|---|---|---|
| 註冊到交付 | 同一批有效註冊孩子；未交付仍在分母 | 已可存取第一份教材；另報等待中／失敗 |
| 48 小時開始率 | 第一份已可用且觀察滿 48 小時的孩子 | 可用後 48 小時內至少一筆有效保存作答；開啟另列 |
| 7 日再次作答率 | 第一份已可用滿 7 日的孩子 | 7 日內至少兩個不同 UTC 日期有有效作答；這只是代理指標，非兩次獨立學習 |
| 第二份使用率 | 第一份可用滿 28 日的原始孩子群 | 28 日內第二份至少一次有效作答；沒請求或未交付者仍留分母 |
| 第二份交付後啟動率 | 第二份已可用且滿 48 小時者 | 48 小時內開始第二份；用來分離交付與使用問題 |
| 支援成本 | 同批孩子 | 每家庭人工分鐘、錯誤／儲存問題、生成重試與服務成本 |

每個指標同時列人數、比例、時間範圍、未成熟觀察數、缺失訊號數。未滿觀察窗者列 pending，不算流失；觀察窗成熟後沒有回來者不能因失聯被刪掉。只剩高動機家庭的完成者分析不得冒充整體留存。

紙本另外報家長自述學習，不硬塞入線上有效作答率。無可作答題目的教材單獨列示，避免把不適用視為未學習。沒有活動時區分「無觀察到事件」與「確定未學習」。

## 六、小規模驗證與更新節奏

1. **先建立基線與五條真實路徑觀察**：取得同意後，涵蓋未開始、做一次、再次使用家庭。確認障礙，記錄協助程度；尚未授權發送招募訊息。
2. **先修可直接證實的狀態問題**：開始面板、完成判定、可靠接續。完成桌面與行動尺寸實際操作檢查，再小範圍上線。
3. **兩批各約 10 個家庭，逐批 28 日觀察**：依真實招募能力調整。第一批發現可用性問題後再開始第二批；不可混合不同產品版本而宣稱改善。
4. **工作量／登入修正由證據觸發**：若觀察顯示主要障礙，才加入相應修正。不要同時更改定價、題材、工作量與提醒頻率。
5. **有重複使用後，驗證進步可理解性**：家長能否說出孩子卡點與下一步；再決定是否投資跨份題目比較。

預先建議的停止規則（內部決策門檻，非產業標準）：每批 10 家庭若少於 5 個有有效首次作答，先修啟動；若至少 5 個開始但少於 3 個再次作答，先處理回訪；若回訪僅在大量人工提醒下發生，不擴大投放。小樣本不能證明因果或 PMF。需同時查看絕對人數與家庭原因，門檻不得事後調整來美化結果。

## 七、進步證據的後續設計邊界

同一份重做、看答案後答對、新題獨立答對，必須分開。跨份 target ID 目前不能假設具有相同技能意義；需要人工審核的技能映射與可比較題組。先做 owner-only 的只讀比較，不直接寫 mastery。

比較呈現題數、日期、技能、協助／曝光情形及證據不足。既有 mastery 規則要求不同教材、相隔至少 7 日的正確證據；不可拿一次進步直接覆寫。完整 assessment 的重測限制仍適用，不拿它作每兩週固定考試。

提取練習與延遲測量有研究依據，但研究不是本產品成效：[Roediger & Karpicke 2006](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/)、[Butler 2010](https://andymatuschak.org/files/papers/Butler%20-%202010%20-%20Repeated%20Testing%20Produces%20Superior%20Transfer%20of%20Learning%20Relative%20to%20Repeated.pdf)。前後變化亦可能來自學校、補習或題目差異，不能宣稱產品造成分數提升。

## 八、商業判斷

先驗證「孩子會再用、家長少安排」是否成立，再驗證願付價格。免費持續使用、創辦支持付款、試辦結束後續訂與真人服務付款是不同訊號，不可合併成付費驗證。

每家庭貢獻應以實收扣除支付／退款／稅費、生成重試、儲存通知及人工時間估算。創辦人時間不能當免費；人工協助帶來的留存若無法負擔，尚未形成可擴張模式。先看實際 30／60／90 日貢獻，不以短期小樣本外推終身價值。

## 九、範圍與依據

首輪不改生成 schema、既有教材、收費、免費試辦、配額或 mastery。保留紙本、owner 權限、不可變提交與明確下一份請求。未作答不當錯誤；開放題不自行評分。
