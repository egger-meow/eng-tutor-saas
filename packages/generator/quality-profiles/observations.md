# Human-Maintained Model Observations Log

This document tracks empirical weaknesses, anomalies, and observations across different LLM authoring models.

## Promotion Workflow
1. **Record**: Add empirical observations with timestamp and model tag.
2. **Review**: When an observation recurs across multiple runs or represents a systematic risk, propose promotion.
3. **Promote**: Convert reviewed observation into an active rule inside the target model profile (e.g. `gemini-3.7-flash.md`) or `default.md`.
